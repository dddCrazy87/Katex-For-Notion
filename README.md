# 公式複製到 Notion

在網頁上複製含數學公式的內容時，自動把公式還原成 LaTeX 並包成 `$…$`，貼進 Notion 後直接變成行內公式，不會再出現「LaTeX 語法＋一串重複純文字」的情況。

只在你指定的網站啟用，沒有公式的內容照常複製，不受影響。

## 功能

- **直接用 Ctrl+C／Cmd+C**：不需要額外按鈕或快捷鍵。
- **只選公式的一部分也能複製**：選取的起點或終點落在公式裡時，會自動擴大到整個公式。
- **保留基本排版**：粗體、斜體、行內程式碼、程式碼區塊、標題、巢狀清單、表格都會轉成 Markdown，貼進 Notion 時結構不會跑掉。
- **網站白名單**：從工具列圖示逐一啟用或停用網站，變更立即生效，不用重新整理頁面。
- **安全退回**：選取範圍沒有公式，或網站的公式讀不到 LaTeX 原始碼時，一律交給瀏覽器預設複製。

## 安裝

1. 把 `katex-to-notion` 資料夾放到固定位置（原因見下方「資料夾名稱與位置」）。
2. Chrome 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選擇這個資料夾。
4. 在工具列的拼圖選單裡把「公式複製到 Notion」釘選出來。

## 使用方式

### 啟用網站

1. 打開想複製公式的網頁，例如 `claude.ai`。
2. 點工具列上的圖示，按「在這個網站啟用」。
3. Chrome 會詢問是否允許存取這個網站，同意即可。已開啟的分頁會立刻生效。

彈出視窗下方會列出所有已啟用的網站，按「移除」即可停用。

### 複製到 Notion

1. 在已啟用的網站選取要複製的內容（可以包含文字，也可以只選公式）。
2. 按 Ctrl+C（Mac 為 Cmd+C）。
3. 到 Notion 按 Ctrl+V 貼上，`$…$` 會自動轉成行內公式。

## 支援範圍

| 情況 | 是否支援 |
| --- | --- |
| 使用 KaTeX 且有輸出 LaTeX 原始碼的網站（Claude、ChatGPT 等） | 支援 |
| 使用 KaTeX 但沒有輸出 LaTeX 原始碼的網站 | 不轉換，走預設複製 |
| 使用 MathJax 的網站（如 Stack Exchange） | 不支援 |
| Notion 網域（notion.so、notion.site、notion.com） | 刻意不開放啟用 |
| `chrome://` 等瀏覽器內部頁面 | 無法啟用 |

**判斷網站是否支援**：在公式上按右鍵→「檢查」，如果找得到 `<annotation encoding="application/x-tex">`，就能使用。

**為什麼排除 Notion**：Notion 自己也用 KaTeX 顯示公式。如果在 Notion 裡啟用，Notion 內部的複製貼上會被轉成純文字，toggle 等格式會遺失。

## 輸出格式

- 行內公式與獨立一行的公式都輸出為 `$…$`。獨立公式會自己佔一行，但貼進 Notion 後是行內公式，不會置中。
- 表格裡公式的 `|` 會改寫成 `\vert`（`\|` 改寫成 `\Vert`），避免被當成表格分隔線。
- 段落之間只換一行，避免 Notion 產生多餘的空白區塊。

## 自訂設定

設定位於 `content.js` 開頭的 `CONFIG`：

| 設定 | 預設值 | 說明 |
| --- | --- | --- |
| `inline` | `['$', '$']` | 行內公式的前後符號 |
| `display` | `['$', '$']` | 獨立公式的前後符號。在 Notion 裡，`$$…$$` 會變成置中的區塊公式 |
| `onlyWhenMath` | `true` | 選取範圍沒有公式時不攔截複製 |
| `listIndent` | 4 個空白 | 巢狀清單每一層的縮排。層級被攤平時可改成 `'\t'` 或 2 個空白 |
| `blankLineBetweenBlocks` | `false` | 段落之間是否空一行 |

修改後到 `chrome://extensions` 按這個擴充功能的重新載入鍵。

## 自訂圖示

圖示放在 `icons` 資料夾，用相同檔名覆蓋即可：

```
icons/icon16.png
icons/icon32.png
icons/icon48.png
icons/icon128.png
```

- 必須是 PNG，Chrome 不支援 SVG 圖示。
- 只有一張圖也可以，四個檔名都用同一張正方形圖（建議至少 128×128），Chrome 會自動縮放。
- 替換後需要重新載入擴充功能。

## 資料夾名稱與位置

資料夾可以取任何名字，程式不受影響。但未封裝擴充功能的 ID 是由資料夾路徑決定的：

- 載入後才改名或搬移，原本的擴充功能會找不到檔案，需要移除後重新載入。
- 重新載入後 ID 會改變，已啟用的網站清單與網站權限都會重置，需要重新啟用。

因此建議先決定好名稱與位置再載入。若需要經常搬移，可以在 `manifest.json` 加入 `"key"` 欄位固定 ID。

## 權限說明

| 權限 | 用途 |
| --- | --- |
| `storage` | 儲存已啟用的網站清單 |
| `scripting` | 在已啟用的網站自動載入轉換程式，或在啟用當下直接注入 |
| `activeTab` | 在彈出視窗顯示目前分頁的網址 |
| 選用的網站權限 | 只有在你按「在這個網站啟用」時，才會針對該網站要求 |

所有處理都在瀏覽器本機完成，不會傳送任何資料。

## 疑難排解

**按了「在這個網站啟用」沒有反應**
到 `chrome://extensions`，點這個擴充功能的「Service Worker」連結，查看主控台的錯誤訊息。

**複製後仍然是重複文字**
- 確認彈出視窗顯示「已啟用」。
- 確認該網站有輸出 LaTeX 原始碼（見「支援範圍」）。
- 在頁面按 F12 開主控台，若出現 `[公式複製到 Notion] 轉換失敗`，代表轉換時發生錯誤，已改用預設複製。

**貼進 Notion 後公式沒有轉換**
- 確認是用 Ctrl+C 從已啟用的網站複製，而不是從其他來源複製。
- 在 Notion 選取公式內容，按 Ctrl+Shift+E（Mac 為 Cmd+Shift+E）可手動轉換。

**巢狀清單的層級不見了**
把 `CONFIG.listIndent` 改成 `'\t'` 或兩個空白後重新載入。
